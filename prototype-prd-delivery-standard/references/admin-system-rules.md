# Backend/Admin System Rules

Use for admin panels, operation consoles, CRM/ERP-like systems, review systems, configuration pages, and dashboards.

## List Page

Define:

- Search fields.
- Filter fields and default values.
- Table columns and data sources.
- Sorting and pagination.
- Row actions.
- Bulk actions.
- Empty state.
- Export permission and scope.

## Detail Page

Define:

- Primary record fields.
- Related records.
- Status timeline.
- Audit logs.
- Operator info.
- Edit/review actions.
- Permission-based visibility.

## Edit/Create Page

Define:

- Field type.
- Required/optional.
- Default value.
- Validation rule.
- Save draft, submit, publish behavior.
- Unsaved-change confirmation.
- API failure fallback.

## Review Page

Define:

- Review status.
- Approve/reject actions.
- Required comments.
- Re-review conditions.
- Status transition.
- Notification rules.
- Audit logging.

## Configuration Page

Define:

- Config key and value type.
- Effective scope.
- Effective time.
- Conflict rule.
- Default fallback.
- Publish/rollback behavior.
- Operator and audit trail.

## Dashboard Page

Define:

- Metric definition.
- Calculation source.
- Time range.
- Refresh rule.
- Drill-down behavior.
- Export behavior.
- Empty/error state.
